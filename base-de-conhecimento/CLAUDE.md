# Contexto permanente

Este arquivo é o ponto de entrada da base de conhecimento. Leia-o antes de
responder qualquer coisa neste projeto.

## Ordem de leitura

1. `01-knowledge/perfil/` — quem é o usuário, como trabalha, o que prefere.
   Leia sempre, é curto.
2. `01-knowledge/INDEX.md` — índice das notas. Leia os títulos e abra só o que
   for pertinente à tarefa.
3. `01-knowledge/decisoes/` — quando a tarefa reabrir algo já decidido.
4. `02-agents/<papel>.md` — quando a tarefa corresponder a um papel definido.

Não carregue `00-raw/` por conta própria. É material bruto, não destilado, e
pode conter versão superada de algo que já virou nota. Só leia um arquivo de
`00-raw/` quando o usuário apontar para ele.

## Como usar o que está aqui

- Nota de `01-knowledge/` é premissa: aplique sem pedir confirmação a cada vez.
- Nota e nota se contradizendo: vale a de data mais recente, e **avise** que
  havia divergência.
- Nota com mais de um ano sobre assunto que muda (preço, ferramenta, norma):
  use, mas diga que pode estar vencida.
- O que não está na base, não invente que está. Diga que não há nota sobre isso
  e ofereça criar uma.

## Como alimentar a base

Quando aparecer, no meio de uma conversa, uma preferência estável, uma decisão
com motivo ou um aprendizado que vai se repetir, ofereça registrar: proponha a
nota pronta, no formato de `01-knowledge/_template-nota.md`, e deixe o usuário
aprovar. Não escreva em `01-knowledge/` sem aprovação — é a parte permanente.

Escrever em `00-raw/inbox/` é livre.

## Higiene

Nunca grave neste diretório: senha, token, chave de API, dado pessoal de
terceiro identificável, documento sob sigilo. Se aparecer numa captura, remova
antes de destilar e avise o usuário.
